#696 文本資料集上架整合測試清單

本清單尚未執行。須在授權的隔離測試環境使用測試資料，並確認 migration、前後臺服務、檔案儲存及測試帳號可用。測試前確認不會寄送真實信件或產生對外公告；使用測試收件者和測試公告設定。不得將帳密或會員個資記錄於測試結果。

前置條件

  • 準備同一級機關的資料管理者、兩位機關資訊業務、另一機關的機關資訊業務、系統管理者與測試會員。
  • 記錄測試版本、環境、測試帳號角色及 migration 狀態；確認前後臺建置與服務正常。
  • 準備兩個不同格式的測試檔、同名替換檔，以及格式或大小不符的測試檔。
  • 公告及信件範本須經確認後才能測試實際文案；若尚未設定，記錄為未驗證，不以手造文案視為通過。

新增並上架

  1. 資料管理者新增資料集，填寫必填欄位及分類，包含「其他」補充名稱，上傳兩個檔案並儲存草稿。確認後臺預覽、歷程與檔案下載；前臺查不到草稿。
  2. 分別確認必填不足、名稱重複、描述與名稱相同、日期顛倒、超過 20 檔及超過每檔 100 MB 時，系統拒絕不合法操作並保持可恢復狀態。
  3. 選擇同機關審核人送審，確認狀態、歷程及列表；非指定人員和跨機關人員不能審核。重複送出不得產生重複申請。
  4. 指定機關審核人同意後，確認轉為系統管理者審核中；系統管理者同意後立即轉為已上架，並記錄上架時間，無資料轉換階段。
  5. 前臺依名稱、描述、提供機關及應用領域查詢，確認列表資料、格式、排序、詳目與實際上架版本一致。「其他」篩選可查到該筆，列表顯示「其他」，詳目顯示補充名稱。
  6. 全公開資料的 ZIP 含兩個正確檔案；AI 限制資料未取得授權時，直接呼叫下載 API 仍不可下載。已登入會員可評分、訂閱及取消訂閱。
  7. 確認新增公告事件唯一且內容、文本標籤符合已確認範本；公告處理失敗時，事件可追蹤且不重複建立公告。

退回、抽回、修改與下架

  1. 機關與系統審核各測試退回，確認退回原因、歷程、重新編輯及重新送審；缺少退回原因不可退回。機關審核中測試抽回及取消申請。
  2. 修改已上架資料的欄位、分類及檔案：新增、移除及同名替換。審核頁能比較並下載前次上架檔案；審核期間前臺持續顯示與下載舊版本。
  3. 修改經兩階段同意後，確認前臺切換到新版本並更新上架時間；依已確認需求不建立修改公告。取消或退回修改時，前臺舊版保持可用。
  4. 送出下架申請並經兩階段同意，確認前臺列表、詳目及下載不再提供該資料集；確認下架異動公告事件與文本標籤。取消、退回或抽回下架時，既有架上版仍可使用。

並行、失敗與資料保留

  1. 兩個操作使用同一舊版本同時儲存／送審；僅允許符合最新狀態的操作成功，另一操作應回報衝突，不能覆蓋已完成的變更。
  2. 模擬檔案儲存或資料庫交易失敗，確認草稿、版本、資源關聯、狀態及事件不會留下不一致資料；重新操作後可恢復。
  3. 測試同機關移轉已上架資料集，確認識別碼、訂閱、回饋、首次上架時間及移轉歷程保留；跨機關或非已上架資料不可移轉。
  4. 每項測試記錄結果、時間、測試版本與可重現步驟；未執行或受環境限制的項目標記未驗證。
